# 统计口径:判断信号还是噪声

来源:`docs/research/improver-design-2026-09-23.md`、`oracle-study-2026-09-23.md`、`batch-study-2026-09-23.md`、
`geometry-lab-2026-09-23.md`。研究 loop 的单次回测**不做**下面这些检验;复盘时要做的是「指出没做」,而不是假装做了。

## 数据切段(训练 / 验证 / 留出)

- 训练 50%(可内部 4 折滚动前推)/ 验证 25% / 留出 25%。只在训练段挑参数和规则;验证段只用来复验;
  留出段每条谱系只用一次,用完不许回头再挑。研究 loop 的全窗口报告只有 70/30 的样本内外标注,不是正式留出。
- 挖掘样本和检验样本之间要留出标签视野长度的隔离带(事后标签看未来 N 根,就隔 N 根)。

## 门槛(改进环默认值,需 Jacky 确认的数字以设计文档为准)

- 每折 ≥ 10 笔、全段 ≥ 30 笔;最大回撤 ≤ 35%;手续费 ×2 后收益仍为正;跑赢同敞口持有;参数邻域是平台而不是孤立尖峰。
- 落库(批量研究):验证段 n ≥ 30、扣成本每笔期望 > 0、手续费 ×2 仍 > 0、跑赢同敞口持有,四条同时满足。

## 三个基准

- 买入持有:同窗口、同费率。
- 同敞口持有 = 持有收益 × 策略平均敞口(做空取负号)。它回答「择时本身有没有贡献」。粗算,长窗口复利下只作方向判断。
- 资产池等权持有:多资产策略的公平基准。

## 随机入场基线

- 同一条执行路径、同样的止损 / 止盈 / 追踪 / 信号离场,只把「什么时候入场」换成随机;笔数与敞口对齐策略;固定种子重复 20–200 次。
- 看策略落在随机分布的第几百分位。oracle 研究里三条规则落在第 0–6 百分位 = 入场比随机还差。

## 试验次数折算(Deflated Sharpe)

- 试验数 N = 这条谱系累计评估过的全部配置(变体、筛资产版本、组合族都算)。方差取所有配置同一段日夏普的方差。
- DSR ≥ 0.95 才算扛住多重试验。20/50 EMA 改进环跑了 3 代 24 个候选,DSR ≈ 0。

## 置换检验:必须保留时间结构

- 相邻 K 线的标签几乎相同(设计效应 18–20,有效样本只有名义的 1/18);行情以周、月成段聚集,多个币同步。
- 同一份数据三种零分布:逐根打乱 p = 0.005、块重排 p = 0.045、同步循环平移 p = 0.27。只有最后一个可信。
- 置换要把「挑最优」这一步整个重跑,零分布才包含选择偏差。

## 多重检验

- 对全部试过的规则做 BH(FDR 5%)。单条 z 检验要乘设计效应。BH 也挡不住成段聚集(oracle 做空的 688 条「显著」几乎全带「周末」)。

## 配对比较

- 同一批入场上比较两个方案:逐笔差值 + bootstrap(5000 次)95% 区间。区间跨 0 → 分不出。
- 样本量:配对差标准差 σ,想以 80% 把握测出 δ 的差距,大约需要 (2.8σ/δ)² 笔。几何实验里 σ≈0.75R、δ=0.2R 要约 110 笔;n = 20 什么都判不了。

## 标签口径陷阱

- 「≥ 2R 的比例」奖励波动率:止损被成本下限放宽时,低波动段很难跑出 2R,好点天然集中在高波动时段。
  这种提升来自 R 的定义,不是入场优势。换成逐根净 R 或波动归一化收益再挖。

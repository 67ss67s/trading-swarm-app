# 市场中性残差回归离线实验（2026-09-12）

## 预注册（结果计算前固定）

需求源：内部评审记录 §3 第2条。假设是多样化研究方向，不预设 alpha。固定三次 trial：BTCUSDT/ETHUSDT、SOLUSDT/ETHUSDT、BNBUSDT/BTCUSDT；均为主流永续候选，报告训练期成交额代理，不以事后收益更换候选。数据窗口固定为 2026-03-16 04:00 至 2026-09-12 04:00 UTC（180d），只读本机缓存；缺失历史由 lab 脚本经环境代理限速补充。任何数据缺口阻断该 trial，不能填平价格或将缺失 funding 当零。

训练使用 anchored 60d 起步，24h purge，完整20d OOS，折间24h隔离（共5折）。log(A)=alpha+beta*log(B)+residual，OLS 在各训练窗估计，样本均值/标准差冻结。稳定性仅在训练窗估残差 AR(1)，要求 0<phi<1 且半衰期在[1,24]小时、beta>0；不通过的折仍记录，不交易、不调整阈值。只用收盘信号，2≤|z|<3 开仓（|z|≥3 已到止损区，不新开）；z跨0退出、|z|≥3止损；下一根开盘成交，最长24根，期限末收盘强平。双腿固定数量、总初始名义归一为1，A权重1/(1+beta)、B权重beta/(1+beta)，不宣称美元或真实市场 beta 严格中性。

每腿每边 taker 5bp、slippage 1bp，按实际退出名义扣费，按持仓方向及资金费时点前已完成小时价格估资金费名义（OHLC代理，非 mark 精确结算）。双倍成本将手续费、滑点、资金费支出翻倍，资金费收入不放大。无交易对照为0；单腿对照沿用同一信号/退出时点，A独立名义1。不同步压力固定为B腿入场及退出延迟1根，A维持原时点；预留额外bar，避免折边界泄漏。

每对只持一仓；所有候选合并统计时每对资本1/3。有效簇采用UTC 24h信号日聚合（覆盖最长持有期），跨币同日同簇；循环移动块bootstrap 2000次、seed=0x51a7、block=ceil(sqrt(n))，CI为每簇平均净收益95%区间。报告原始成交数、有效簇、净收益/毛收益/费用/滑点/funding、最差成交及5%尾部均值、初始与持仓净美元暴露。有效簇<30、完整折<3、CI下界≤0或双倍成本净收益≤0均拒绝；合并结果不挽救失败单对。三对均保留trial，禁止扩搜索补救。24h簇仅为保守代理，仍可能有跨日依赖；移动块用于减轻这一限制。

## 执行边界

只提供离线 PairSignalFn/PairSetup、双腿结算及研究注册表，不创建策略库记录、不接议会、不进active、不下单。现有入口仅一个symbol和一个direction，不能承载双腿。未来需要JSON Schema双腿plan/outcome、联合风险与审批plan_hash、双腿数量和舍入、资金预留、两腿CID调用前持久化、部分成交/不同步/补偿退出/unknown恢复协议、execd账户单写者与保护腿验证；完成前延后线上接入。现有晋升门不变。

## 复跑

`npm run lab -- --study pair`。历史快照位于运行时缓存，结果写 内部评审记录，包含预注册、数据hash、每折模型与所有成交；缺失时脚本补数据，失败明确阻断。测试：`npm test`；类型检查：`npm run typecheck`。

## 审查后的实现收紧（非扩大搜索）

独立Codex对抗review发现资金费覆盖、空费率、延迟数量、暴露采样和边界收入问题，均已修复。四币实际历史均为每8h一次、各540条；实现明确限定该UTC网格，变频历史阻断而不猜测。费率必须为十进制字符串。不同步压力沿用基准B腿数量；净美元暴露采开盘成交前/后及收盘（仍不代表小时内极值或真实市场beta）。成交恰逢资金费边界时仅计支出、不计不确定收入。以上不改候选、训练阈值或OOS口径，复跑结果一致。

95% CI为逐trial区间，未做三次比较的族级校正，因此即使出现正下界也只能列离线待证据，不能宣称全族显著或晋升。真实数据无成交，合成数据测试仅验证实现，不计入真实研究有效簇。

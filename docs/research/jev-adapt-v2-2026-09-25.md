## E2E 根因与证据边界

`judge_probability_sum` 旧版对完整分布要求 |sum−1|≤1e-6；客户端此前只传解析后的答案，没有供应商原文。现在先落脱敏 `raw_response`（model/id/answers/usage；非JSON保存脱敏body_text），无论解析是否成功均有 `raw_response_ref` 和费用。`judgeDiagnostics`/CLI 可导出命中的原始概率、sum、deviation 与最大偏差。E2E报告没有51条分布；禁止读取demo，因此本轮不能声称51次全是四舍五入。新增 parser `judge_answers_v2_rounding_001` 明确接受0.99–1.01并归一，v1保留原行为，新 profile 显式选择后才使用。应先审核真实脱敏统计再迁移。

`judge_unknown_cost_calls` 可复现的代码原因：客户端解析答案抛错后丢掉 usage；非2xx的usage未传递/未进客户端日账；cost字符串不识别；研究费用结算错误地依赖 input_tokens 合法。均已修复，HTTP/坏答案仍按已知费用记账，调用前已知未发送的校验失败记0。超时、断网、进程中断、供应商不返回cost依旧unknown并保留上界；禁止为获取费用重抽。单次收费请求固定 `maxRetries:0`。11次真实unknown的分类须脱敏账本，不能由报告总数反推。

## runtime 接线（合并）

所有模式均由 StrategyRunDeps.microstructure(symbol,as_of) 提供已在候选时点可用的快照；历史通过同一接口提供录制覆盖。不要把当前现拉的盘口回填到更早 as_of。实时公共接口应经现有合规数据服务提前缓存，基础币数量换算使用冻结的线性合约元数据。下面依赖不包含密钥或交易写操作：

```ts
import { recordingMicrostructure } from './research/judge/recordings.js';
import type { MicrostructureSource } from './research/judge/microstructure.js';

const recorded = recordingMicrostructure({
  directory: `${os.homedir()}/.trading-swarm-okx/micro/data`,
  instruments: frozenLinearInstruments, // {BTCUSDT:{inst_id:'BTC-USDT-SWAP',base_per_contract:十进制ctVal}}
  availability_lag_bound_ms: verifiedRecorderLoopBoundMs,
  // 老录制器没有 heartbeat；留空即清算不可评。升级后接成功轮询覆盖证明。
  coverage: (symbol, as_of) => pollCoverageAt(symbol, as_of),
});
const microstructure: MicrostructureSource = async (symbol, as_of) =>
  publicMicroCache.snapshotAvailableAt(symbol, as_of) ?? await recorded(symbol, as_of);

// StrategyRunService 的 deps 对象加：
{ microstructure }
// MatrixStudyService 原 judge deps 对象加（不要仅给 live source）：
{ provider: pinnedJevProvider, microstructure: recorded }
// 新 profile 必须新 ref/revision，不修改已有冻结 profile；确认偏差后可选：
{ parser_version: 'judge_answers_v2_rounding_001' }
```

微观字段全标 live_only；缺录制覆盖返回 `judge_live_only_data_unavailable`，matrix 中为 `DATA_MISSING:judge_live_only_data_unavailable` / insufficient_evidence（数据不可评），不是全skip获利。原始盘口只有200档；不是完整0.5%深度。旧清算录制的px来自bkPx，因此名义额按该录制价格估算，不等于逐笔成交额。清算API样本上限/漏采不视为全市场总额。无轮询覆盖证据时不填写清算额。旧录制时间是循环开始时间，必须提供整个循环耗时可靠上界，不能只用单次HTTP超时。

## G3：四臂 v2

新增 `jev-g3.mjs`：code、cheap_trend（1h和4h SMA20/SMA50均与方向一致）、jev、deepseek。保留旧G3六臂接口；本任务四臂v2没有伪造cash/matched_random。≤3个finalist/开发候选、训练截止、问题/规则、模型profile、执行规范、资本风险约束、费用上界与分析门槛冻结进manifest。候选清单中的state经白名单验证；给两模型同一state/questions/criteria，不发送未来成交结果。DeepSeek直连 `https://api.deepseek.com/chat/completions`，模型`deepseek-chat`；Jev钉住`typesafe/jev-1.13-20260917`。DeepSeek模型别名不证明权重永久不变，实际响应模型/ID随原文留存。

类型见 `g3-collect.ts` 的 `G3CollectionManifest`，从冻结finalist或matrix开发候选导出（本轮没有可交付的真实finalist）。每个opportunity包含candidate、buildJudgeState结果，以及当时已收盘1h/4h bar；不要从实时demo目录提取。本脚本不自动连接运行库或拉行情。`g3-fixture.ts` 是字段形状示例，只能作离线演练；禁止把synthetic改false后当真实证据。

采集账本位于独立路径，SQLite原子预留/首次响应保证续跑不重复收费；CLI独占PID锁、失去旧worker后将pending转unknown。库函数默认不恢复pending，只有拥有独占权才可传`recover_interrupted:true`。一个DB只允许一个manifest、同一预算；不允许换manifest重置额度。unknown占用最大预留，预算不足未采齐标complete=false；供应商实际超预留照实记录并封锁后续。预算硬闸依赖冻结单次费用上界成立，无法控制供应商超额计费。不要沿用未核验的规划单价当真实价格上界。

DeepSeek有usage.cost时用供应商费用，否则依据usage输入/输出token和manifest冻结单价（缓存输入按未缓存上界）计费，原文标`frozen_token_tariff`，不是账单核验。输入UTF-8 bytes上限+1024 framing与max_tokens约束每次预留；上界不足先拒绝manifest。Jev按冻结max_call_usd预留。$2是整次采集含unknown的硬停止预算，不承诺一定覆盖6000个机会；三finalist无法共享状态时可能不足。

真实执行（环境中预先提供 `OPENROUTER_API_KEY` / `DEEPSEEK_API_KEY`，不在命令打印、不读密钥文件）：

```sh

# 中断后原样再执行上面命令；已录制不重收费。
node packages/gateway/scripts/research-study-eval/jev-g3.mjs \
  --mode analyze --network deny \
  --manifest /tmp/g3-frozen-manifest.json --collection /tmp/g3-collection.json \
  --outcomes /tmp/g3-execution-outcomes.json --output /tmp/g3-analysis.json
```

分析所需`G3Outcomes`由同一冻结执行器独立导出每个候选的条件成交路径，必须包含手续费/滑点/资金费、入场/离场时刻、跨日净盯市点和执行hash；采集脚本不读该结果文件。未成交机会使用 `{candidate_id,status:"not_filled",reason:"expired"|"invalidated"|"execution_rejected"}`，不填写虚构的entry/exit/marks；仍保留候选和查询费用，不计实际开仓follow。分析统一起始资金/风险/最大持仓/总名义/同资产冲突，按已实现权益定仓、每日净盯市估值，失败skip保留候选，模型费按调用UTC日扣，共享请求跨finalist均摊。它不是把每笔机会R相加；路径依赖离场/加仓策略需要执行器给出正确条件路径，分析器无法独立证明成交文件真实。

主要终点：同UTC日账户净收益Jev−code、Jev−cheap_trend；同步连续块bootstrap10000次、块长≥持仓天数、跨≤3finalist及两声明Bonferroni同时CI。6000候选、365日、100次实际开仓follow、20块门槛，净收益>0、日净值回撤≤冻结上限且≤35%、CI下界>min_effect。不足、桩或unknown费用均不宣称通过；DeepSeek只探索比较。原始机会、响应、费用、outcomes及各hash须一起留存。

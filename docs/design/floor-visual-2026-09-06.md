# 楼层视觉 v2:背景/地板/排位 — 2026-09-06(我的创意稿,待与 Codex astra 方向对齐)

背景:Jacky 觉得楼层地板「黑底 + 网格线 + 暗角」太素,要更有设计感;并考虑把楼层做成产品主打(侧栏第一、可能默认首页)。
约束:纯 CSS/SVG 内联,不引图片、不加库;动效只动 transform/opacity;四套配色都成立;不遮桌子/气泡/飞包;≤ 1 个持续动画。

## 我的三个方向

### 甲 · 交易大厅(Trading Floor)
概念:不是机房,是老交易所的交易池——地板分区,每张桌子有自己的「席位地毯」和顶灯。
- 地板:两层。底层 `--of-bg` 上铺一张斜 45° 的细木纹/地砖(两条 `repeating-linear-gradient` 交叉,间距 22px,透明度 3%),外围一圈墙面(顶部 60px 用 `--of-panel-2` 做「墙 + 踢脚线」,墙上挂三块「牌子」= 现在的三块小屏,天然解释了小屏为什么在上面)。
- 分区:三条横向走道(y=33%/66%)用一条 1px 亮线 + 两侧 6px 的暗带表示,走道尽头有出口标识(RADAR 侧「情报区」、LAB 侧「研究区」、下方「执行区」)——用 `.of-zone-label` 竖排 kicker 贴在墙上。
- 桌位:保留 3×3,但每桌下面一块椭圆「席位地毯」(`radial-gradient`,颜色 = 角色色 8%),干活时地毯亮到 16%(这就是现在 of-spot 的升级版,颜色从统一绿变成角色色)。
- 顶灯:每桌上方一个 2px 宽、渐隐的锥形光(`linear-gradient` + `clip-path: polygon`),只在 working/thinking 时出现,静态。
- 风险:元素多了,1440 宽以下会挤;需要把走道位置和桌位一起按百分比算。

### 乙 · 蓝图/示意图(Blueprint)
概念:楼层是一张工程蓝图,桌子是图纸上的模块,交接是图上的线。
- 地板:细网格(现在的 40px)保留但改成两级:主格 120px 亮线 + 次格 24px 暗线,四角放尺寸标注(纯装饰 kicker 如 `DECK 01 / 1000×560`,ops 文案模式才显示)。
- 加「静态连线」:按 notebook §3 的拓扑,在桌子之间画 SVG 折线(radar→helm、helm→thread、thread→exec、exec→sentinel……),线色 `--of-line`,交接飞包就沿这些线飞(现在是直线,改成沿折线只要把 packet 的 left/top 分两段过渡)。
- 桌位:保留 3×3;每桌加一个左上角的「模块编号」小标签(01–08)。
- 风险:最省力、最贴合「系统图」的定位,但离 Jacky 参考物的「像素办公室」感觉最远;paper 配色下要把线加深。

### 丙 · 像素办公室(Pixel Office)
概念:把参考物做足——真的是一间像素风办公室,有地毯、盆栽、白板、咖啡机。
- 地板:8px 的像素方格地毯(两色交替 `conic-gradient` 或 `repeating-conic-gradient`),中央走道用另一色;墙面顶部一条 24px 的「像素墙裙」。
- 道具:用 box-shadow 位图再画 4–5 个静物(盆栽 ×2、白板、饮水机、服务器机柜),放在桌子之间的空位;白板上写当天 regime/bias(把左栏「市场状态」的一行搬到白板上,信息不重复而是换个载体)。
- 桌位:保留 3×3;桌子改成像素画(桌面 + 两条腿 + 显示器背面),显示器背面对着观众更像参考物。
- 动:只有饮水机气泡/服务器灯这一种循环动画(可关)。
- 风险:工作量最大;道具容易变成花瓶(Codex 之前的批评);paper 配色需要单独调色。

## 我的推荐

**甲为主,吸收乙的一点**:甲的「席位地毯用角色色」和「墙上牌子 = 三块小屏」解决了现在两个真实问题(桌子和角色色没关系、小屏悬空没理由);从乙借「静态拓扑连线」让交接飞包有路可走、也让「谁把活交给谁」不用读文字就能看懂。丙留到有 hackathon 视频需求时再做道具。

## 与 Codex astra 的对齐(05:0x,`.codex-reports/floor-visual-design.md`)

Codex 三个方向:**值班舰桥**(双纵走道 + 横向通廊 + 薄墙裙,推荐)、**系统蓝图**(稀疏点阵 + 外围虚线框 + 中央静态定位环)、**模块工坊**(三条宽地毯把桌子分成三组)。对应关系:舰桥 ≈ 我的「甲·交易大厅」的走道/墙面部分;蓝图 ≈ 我的「乙」但 Codex 明确反对画拓扑连线(会被误读成权限或交接路线),只留静态低反差;工坊 ≈ 甲的席位地毯部分,但 Codex 提醒「同一块地毯会暗示同权限」。Codex 额外的硬约束:背景零动画;所有装饰在桌子之下、不接收点击;背景不用警告色;四套配色都从 --of-* 变量派生(paper 要把黑色气泡/屏幕换成 --of-panel);现有飞包 left/top 过渡和打字 clip-path 要改成 transform/opacity;reduce-motion 要关掉 walking。

### 楼层视觉 v2(合成后的推荐)

**骨架 = 舰桥**:Codex 的双纵走道(列间 16px 面板色)+ 横向通廊(y=66%,14px)+ 8px 内边的薄墙裙(墙线混 12% 强调色),去掉现在的径向暗角。这一层四套配色直接成立,CSS 就是 Codex 方向一那段。
**分区语义 = 我的甲**:三个区用墙上的竖排 kicker 标「情报区 / 指挥区 / 研究区 · 执行区」,只做文字不做地毯,避开「同毯同权限」的误读。
**桌位 = 角色色席位**:每桌下一块椭圆席位光(角色色 8%,working/thinking 时 16%),替代现在统一绿色的 of-spot;这是唯一带角色色的地面元素,面积小、在桌子正下方,不会被读成分区。
**顶部三块小屏 = 墙上的牌子**:把小屏容器贴到墙裙上(去掉小屏与地板之间的 8px 缝,小屏底边与墙裙顶边共线),解决「小屏悬空没理由」。
**不做**:拓扑连线(Codex 反对)、盆栽/白板等道具(丙留给视频)、任何背景动画。
**顺手修**:飞包已被走动替代,剩余 clip-path 打字气泡改成 opacity 淡入;reduce-motion 时 walking 位移归零(motion.ts 已按 reduceMotion 跳过,CSS 再兜一层)。

### 排位与首页(两边一致)

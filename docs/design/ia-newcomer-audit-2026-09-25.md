# 前端信息架构审计:新手视角(2026-09-25)

> 对应 chat-to-strategy-loop-2026-09-25.md 的 R20。只读审计,未改代码。分支 wt/strategy-loop,前端 `packages/webui/src`。
> 视角:第一次打开、不了解系统的交易用户。楼层内部布局归楼层 v4,这里只评它在导航中的位置。
> 行号以本分支 2026-09-25 的代码为准,实施前重新核对。

## ① 结论

1. 导航按「系统有哪些角色」分组(值班/交易/团队/回顾/系统),不是按「用户要做什么」分组。新手的主线是「接入 → 选币 → 找策略 → 让 agent 跑 → 看结果」,在现在的侧栏里被拆到 4 个分组、9 个页面:选币入口「筛选」放在「团队」组,找策略的「研究工作台/我的策略」放在「回顾」组,交易所接入根本没有页面。
2. 决定能不能交易的几样设置都藏在 Agent 页右栏「执行」tab 里:账户模式、保护单验证(这一项不标,闸门就不放开新开仓)、「简单模式开不了永续」的警告。默认首页「楼层」只会引导去接模型,不会引导接交易所、选账户模式。同一件事还有两三处入口且不一致:观察列表/节奏在设置页和盯盘页各有一套组件;大脑在顶栏、设置页、模型连接三处;交易市场、杠杆、保证金模式在设置页,账户模式却在 Agent 页。
3. 改法:先加一个「开始」清单页,再加一个独立的「接入」页,两者都可以马上做,不依赖新功能。侧栏按旅程重排成 5 组,另设一个折叠的「高级」组,把信号市场、信息员、事件区、日志、实盘部署台收进去。「推荐 → 研究 → 设为当前策略」这条链现在缺一环(我的策略没有「设为当前策略」按钮),要等 R5 联调后再定位置;矩阵研究页本身审计时已核实是通的(`#matrix-study?from=` 正确接住并预填),不是死链。

## ④ 每个页面的问题与改法

- **楼层(默认首页)**:首屏是 4 格顶栏(执行后端/调度/今日判断/开着的线程)、6 格底栏(审批模式/风控/敞口/自报信心…)和一个角色楼层,适合老手值班,新手看不懂任何一格(floor.tsx:163-209)。唯一的引导是没有模型时的横幅(:171)。改法:第一次进来且接入未完成时不落在这里(见 ②);横幅扩展成统一的「开工阻塞」横幅,包括交易所未连、简单模式、保护单未验证、没入金(:120 已经算出来但只写进一格)、没有模型。楼层内部布局归 v4。
- **Agent**:左边对话,右边「异常/待办 + 快捷入口 + 状态|执行|团队」(agent.tsx、agent-side.tsx)。问题:「执行」tab 塞了接入类设置(账户模式、凭证、保护单验证、网络检查、币安遗留块),这些是一次性配置,不是值班要看的。改法:「执行」tab 只留只读摘要(后端、连接灯、账户模式、现货持币)和一个「去接入 →」链接,写操作都搬到 `#connect`。状态条上的当前策略胶囊保留。
- **盯盘参数 → 观察列表**:09-24 重设计后首屏是四页里最好的(watch-panel.tsx:147-186 成本条 + 名单 + 节奏)。只需改名,并把设置页那份重复删掉(③-7)。workflow-form.tsx:1-3 的注释已经过期,顺手更正。
- **筛选**:见 ③-10。页内「加入」一键写入(screener.tsx:582-588)和顶部勾选、按 diff 确认(:704-741)两条路径并存,加一句说明:单个加用前者,批量换名单用后者。「立即筛选」按钮(:236-242)做成主按钮。
- **信息员 / 事件区**:两页各自的边界写得很清楚(intel.tsx:1-9「只解释环境,候选归筛选页」;events.tsx:1-10「有生命周期的实体,永远不直接下单」),但侧栏上两个名字字面意思接近。收进「高级」,并在页首各放一句一行的区别说明。
- **信号市场**:页面本身结构清楚(market.tsx 四个 tab 按「市场 → 订阅 → 信号 → 发布」),问题只在导航位置:需要钱包和 ASP 身份,是高级功能,却排在「交易」组第二位。挪进「高级」。筛选页和信号市场之间加一句「另一个币的来源:外部信号」。
- **交易**:给已经有持仓的人用,首屏合格(trade.tsx:956-957)。「线程」这个词没有解释(:1109、:1255),在栏头加一个 tooltip:「一笔交易从挂单到离场的全过程」。下单旁路见 ③-11。
- **研究工作台**:给懂 A/B/C 三臂的人用(research.tsx:1-17 的术语链 Dataset→Study→Policy…),新手门槛很高。另外 §9.54 的新 Study(矩阵)和旧 Study 同名不同物,接线时要改名或合并,避免同一页里出现两个「Study」。研究台的对话(session-chat)和 Agent 对话是两个入口,改法:研究台首屏加一句「从 Agent 对话发起推荐,会带着资产和周期过来」。
- **我的策略**:列表可达,缺「设为当前策略」(③-5);「运行规则」tab 改名(③-6)。
- **实盘部署台(隐藏)**:见 ③-6;在 R1(旧库退出实盘)落地前维持隐藏,但放进「高级」组让人能找到。

## ⑤ 新手首次启动引导(`#start` 清单)

每项显示状态灯和一个动作按钮,完成的自动打勾;全部完成后清单收起到侧栏底部一行「接入完成 ✓」,随时可以再打开。

1. **连接交易所账户**:模拟盘/实盘二选一,新手默认模拟盘。复用 OkxConnectForm(accounts-menu.tsx:36-109,同一份组件)。完成条件:`execution.okx.available`。
2. **选账户模式**:复用 AccountModeSelect(execution-panel.tsx:406)。只做现货就选简单模式;要做永续,选单币种或跨币种保证金。从简单模式第一次切出只能在 OKX 网页上完成(51070),这时给出网页链接和「切完点刷新」。完成条件:`acct_lv` 已知,并且和第 5 步的交易市场兼容。
3. **入金检查**:`account_funded === false` 时给入金链接(agent-side.tsx:72 已有文案)。模拟盘自动跳过。
4. **接模型**:复用模型连接页的添加弹层;至少一个连接测试通过。完成条件:`needsModelSetup` 为 false(components/models/logic.ts)。
5. **定交易市场与风险**:交易市场(永续/现货)、单笔风险、杠杆,只放这三个字段,默认值直接可用,其余去「风控与自动化」。
6. **选币**:两个入口二选一:「让 agent 推荐」(跳 Agent 对话并预填「推荐几个币」)或「去筛选」(首次自动用全市场)。完成条件:观察列表至少一个币。
7. **跑一次研究(可选)**:从推荐卡「去研究台验证」进(链路已通,跳 `#matrix-study?from=`);推荐卡本身还没有固定 UI 入口(只能靠对话打字触发),这一项要等 R2 给推荐卡加常驻入口后才好在清单里默认展开。
8. **设当前策略**:「自由判断」是合法选项,默认就是它;明确点一次「确认」才算完成,这样新手知道这个开关存在。
9. **验证保护单**(只在实盘或要开永续时出现):复用「标记保护单已验证」流程,附上模拟盘验证清单。

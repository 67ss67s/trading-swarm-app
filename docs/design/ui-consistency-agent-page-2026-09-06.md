- 工作流表单整体搬到「设置 › 工作流」,分四组折叠:**节奏**(周期/扫描方式/心跳/急拉阈值/收盘复查/信息员频率)、**风险**(单笔风险/杠杆/保证金/日亏停)、**额度**(最多线程/每日开仓/判断上限)、**自动化**(自动执行/旁白/暂停/playbook)。保存仍走 diff + 部分应用。

不搬东西,但右栏仍然拥挤,20rem 宽度下表单字段仍要两列挤。

### 方案 C:三栏
对话 | 工作流(独立一栏 22rem)| 状态/执行/团队(16rem)。宽屏舒服,1440 以下要折叠,和其他页的两栏节奏不一致。

**我的建议:B。** 工作流是「偶尔改」,对话和状态是「一直看」;偶尔改的东西放设置里、常看的放对话旁边,符合三层监督的分层。

## 4. 角色动态表现(楼层 + 团队卡通用)

原则:动效只动 transform/opacity;每个状态都有「静态可读」的兜底(颜色点 + 一句话),动画只是加强;reduce-motion 全关。
数据来源全部是已有的:presence(网关)、`episode.progress` 步骤、`chat.message`、`activity`、`bots.changed`。

| 状态 / 事件 | 像素人 | 桌子 / 环境 | 气泡 |
|---|---|---|---|
| idle 待命 | 每 4–7 秒随机眨眼(眼睛像素隐 120ms);偶尔换一帧「抬头」 | 屏幕一条暗线慢滚 | 无;hover 显示「下一轮 mm:ss」 |
| thinking 思考(episode fetching→thinking) | 呼吸 + 头顶「…」三点循环 | 桌灯亮(spot);屏幕按步骤点亮 6 格进度 | 「复查 SOL · 模型思考中」 |
| working 干活(radar 筛选、回测跑批) | 呼吸 + 手臂两帧交替(打字) | 屏幕逐行打字(3 条 accent 线依次出现) | 「短线筛选 17/60」带进度 |
| waiting 等着(挂单等成交、待阅) | 上下轻浮;每 10 秒看一眼指挥台方向(sprite 水平翻转) | 桌角黄灯 | 「3 条交接待阅」黄框 |
| blocked 卡住 | 抖动一次后静止,眼睛变「×」两帧 | 桌灯红闪 2 次后常亮 | 红框,文案带原因 |
| done 完成(episode.finished / 回测完) | 跳一下(translateY −6 → 0)+ 头顶「✓」1.5 秒 | — | 短暂显示结果(WATCH / PROPOSE …) |
| off 未接线 | 灰、不动 | 屏幕黑 | hover 显示 note |
| **交接 handoff(真 bot_handoffs)** | 发送方举手一帧 → 包裹飞到接收方 → 接收方点头一帧(translateY 2px 两次) | 指挥桌上「收件」计数 +1 跳动 | 接收方头顶短句 = summary 前 20 字,3 秒 |
| **对话(chat.message)** | 用户发言:HELM 转向用户(翻转)+ 「…」;assistant 流式输出:HELM 头顶气泡打字机逐字(取消息前 40 字);工具调用(`@@tool`):对应角色亮一下(get_thread → THREAD,scan → RADAR) | 指挥桌高亮 | 打字机气泡 |
| 成交 / 止损 / 止盈 | EXEC 盖章一帧(手臂向下)→ 包裹飞给 THREAD | 执行台屏幕闪一次绿/红 | 「BNB 多 已成交 @ 769」 |
| 紧急停止 | SENTINEL 站起(sprite 上移 4px)+ 全场桌灯变红 | 地板网格变红 | 「紧急停止生效中」 |

实现落点:
- `sprite.tsx` 加 `frame`(0/1)与 `flip`;位图加第二帧(手臂/眼睛差异)——每个体型 2 帧即可。
- `deck.tsx` 用一个 `useAnimator(feed, presence)` 把事件翻成短暂的 `pulse` 状态(1.5–3 秒自动清),叠在 presence 之上。
- 团队卡(Agent 页)复用同一套 Sprite + 状态点,不做飞包。
- 声音不做。

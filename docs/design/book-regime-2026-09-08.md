# Book 仓位与市场状态设计（2026-09-08）

## 结论与交付边界

可落地。先分开三个量：市场总持仓量 OI、账户名义敞口、交易所设置的杠杆。小资金不是高风险的理由；同一风险比例下，止损较窄的短线可有较高名义敞口。杠杆主要决定保证金占用，不能替代止损风险预算。当前提供十进制纯函数 book-v1-shadow、独立边界 eval；不把它当成已证实盈利的自动加杠杆策略。

仓位依赖链：策略选方向/周期/结构止损与独立目标 → 持仓计划校验 ATR/净RR → Book分配剩余风险 → 数量与杠杆建议 → 原有组合/流动性/审批/执行重闸。持仓周期不会随某一根短周期反向针被Book重新定义。

## Book v1 的具体规则

预算 B = min(权益 × 用户每笔风险比例 × 市场折扣 × 策略健康折扣，剩余组合止损预算)。

每单位预算损失 = |入场价−止损价| + max(入场价,止损价) × (往返费用滑点bps+持有期资金费预算bps)/10000。

数量上界取以下最小值，再向下取交易所网格：B/每单位损失、剩余敞口/价格、流动性限额/价格、保证金预算×杠杆上限/价格。最小下单量不满足则拒绝，不为了交易抬高风险。

保证金预算 = min(可用资金×50%，权益×25%)。在用户上限内选择满足预算的最低整数杠杆。原型周期上限为 scalp 10 / intraday 5 / swing 3 / position 2；用户当前4倍上限仍优先。这些是待校准的工程默认值，不是论文得出的最优参数。

市场折扣：trend 1 / range .75 / transition .5 / unknown .25 / stress 0；健康折扣 healthy 1 / degraded .5 / unknown .5。策略与市场不匹配应先由策略选择层拒绝，折扣不是所有趋势策略在震荡中仍可交易的许可。除非有效样本证明优势，禁止完整Kelly与模型信心放大风险。

资金越小越容易碰到最小名义门槛，正确行为是换合适标的或不交易。长期仓要预算资金费、跳空及跨时段压力损失；止损预算只是基准损失，不是实际亏损的上界。市场OI可用于拥挤与杠杆去化特征，不能直接拿OI增长换算本账户加仓倍数。

现有Portfolio已做总敞口、风险簇和聚合止损预算硬闸；Book不替换它。v1原型不含交易所维持保证金档位、真实清算价、挂单保证金精确占用，也不具备自主执行资格。生产启用前必须加入这些约束以及原有逐簇/净敞口限额的精确剩余预算。

## 如何识别市场变化

不能用“最近哪个策略赚最多就切哪个”代替识别。市场状态变化与策略本身失效是两件事，需要两条监测链。

1. 市场状态：每个策略自己的已收盘主周期，计算方向效率 ER、归一化趋势强度、实现波动率及过去窗口分位数、波动率短长比、标的间相关性、成交深度/价差、资金费与OI变化。初版采用透明规则输出 trend / range / transition / stress / unknown，并保留原始特征及证据时间。量化状态模型可刻画突变和状态持续性，但不保证预测下一次状态变化。[Ang与Timmermann研究](https://www.nber.org/papers/w17182)
2. 变点告警：对标准化后的波动、相关性与策略残差跑CUSUM/Page-Hinkley；后续对照BOCPD。它们判断近期生成过程是否变化，不直接发交易方向。BOCPD递推“距最近变点的运行长度”分布，可保留不确定性。[Adams与MacKay论文](https://arxiv.org/abs/0710.3742)
3. 策略健康：只用已经结算且费用完整的交易，按策略版本×市场状态×周期记录净R、命中率、盈亏大小、MFE/MAE、持有时长、成本占收益比例。用滚动/指数加权净R与区块bootstrap置信区间判断衰退。参数/提示词/执行路径变更必须分版本，不能拼接成同一个胜率。
4. 状态切换：普通新状态连续3根主周期收盘确认；异常流动性/已核实重大事件立即进入stress；状态不明先降低新风险，不为了改状态平掉所有旧仓。持仓退出仍服从原计划与硬风控。3根是待测参数，须报告确认延迟与误切换次数。
5. 策略选择：维护按状态条件化的策略分数，对小样本收缩到总体/先验；只从已有paper合格策略中选择。分数相近保持原策略，设置最短驻留和切换成本；不把某一段赢家提升到无限风险。策略失效先减预算/转shadow，恢复需要独立后续证据。

若用HMM，线上使用仅截至当时数据的filtered概率，禁止用全历史smoothed状态回填决策。所有归一化、分位阈值、聚类中心只在训练段拟合；每日/每周重新拟合也要存版本，不让未来数据修改历史状态。

波动管理在某些因子研究中有改善风险收益的证据，[Moreira与Muir](https://www.nber.org/papers/w22208)；另一项研究显示实际样本外结果和结构稳定性并不普遍支持该结论，[Cederburg等论文](https://www.lehigh.edu/~xuy219/research/COWY.pdf)。所以本项目把“高波动缩风险”作为候选风险控制，不宣称它给加密合约带来确定alpha。

## Eval及晋升门槛

### Book 确定性验收

已实现测试覆盖：资金10/100/1000/100000、四种周期、四种市场状态共64组组合，另有最小单量、双向止损、费用/资金费、未来/过期快照、未知状态、压力行情、用户杠杆上限、最低可用杠杆等边界。每一笔候选需满足预算、数量网格、名义与保证金限制；这证明代码约束，不证明盈利。

### Book 收益评估设计

冻结同一批入场与退出价格轨迹，对比当前固定risk/4倍配置、成本后固定风险、Book动态预算三臂。不得让Book靠选不同入场样本掩盖仓位差异。按账户规模分层模拟，纳入并发挂单预留、同风险簇多仓、手续费/滑点/资金费、保证金档位与跳空。报告收益、最大回撤、CVaR、保证金占用峰值、拒单率、最小规模不可行率、换手和风险超限次数。先保证零超限；再比较净收益/回撤的区块bootstrap区间。

### 市场与策略状态验收设计

按时间walk-forward，禁止随机拆K线；purge覆盖标签/持有期重叠，gap至少覆盖最长标签周期。TimeSeriesSplit的gap有助于隔离相邻窗口，但不能自动处理所有重叠交易标签。[官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)

四臂消融：不切换 / 市场状态规则 / 策略健康降档 / 两者结合；HMM和BOCPD另作对照，不靠试几十组参数挑最好的一组。记录全部试验数量，多重比较用DSR/PBO或预注册单一候选后锁定最终holdout。大量选参会制造漂亮回测和差的样本外表现。[Bailey等](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2308659)

衡量：净R期望、成本后的收益与回撤、切换成本、误切换率、变点延迟、单次急针后反复切换次数、压力行情亏损尾部。合成突变/噪声只能验证识别行为；真实历史是收益证据，仍不等于未来获利。

建议预注册晋升门槛：至少三个不同状态、每状态至少30笔独立持仓/交易簇（重复调用不加样本数），最终时间留出段成本后正期望，较baseline提升的95%区块bootstrap下界>0，回撤和CVaR不恶化，2倍成本压力仍可接受，关键风控违规0。门槛值属治理选择，应在看结果前冻结；数据不足则HOLD，不写“验收通过”。

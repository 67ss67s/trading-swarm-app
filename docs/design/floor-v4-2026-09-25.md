# 楼层 v4:像素场景为主角(2026-09-25 设计稿,待 Jacky 敲定)

参考:Jacky 给的四张概念图(Research Floor 暖色书房 / Agent Swarm 指挥中心 / Meme Lab 霓虹 / 资产预览)。
现状问题:三栏 + 上下两条统计栏,场景只占中间一小块、桌子是平面的、字比画多;像监控大屏,不像「一群 agent 在上班」。

## 1. 原则

1. **场景是主角**:像素房间占屏幕 ~70%,信息面板退到一条窄右栏 + 一条顶栏。
2. **信息只留三件事**(新用户 5 秒看懂):
   - 要你做什么:待批订单 / 待你确认的交接(有就亮,没有就不显示)
   - 钱怎么样:权益、今日盈亏、持仓数
   - 团队在忙什么:一条人话动态流(「RADAR 发现 SOL 急拉 → 交给 THREAD」)
   其余(判断配额、调度、风控明细、账户快照……)全部收进「点 agent 看详情」。
3. **agent 之间看得见联系**:交接 = 一个发光的「信封」沿地面走廊从 A 桌飞/走到 B 桌;B 抬头接住、头顶冒一句话;多人参与的事(策略信号 → 组合经理 → 风控 → 执行)在中间会议桌短暂「开会」。
4. **像素微动**:30% 的像素在动——显示器扫描线闪、键盘敲击、角色呼吸起伏、眨眼、植物摇、窗外城市灯光/雨、猫尾巴、咖啡热气、空闲角色偶尔伸懒腰/走去茶水间。
5. **可换主题**:同一套布局与引擎,主题 = 调色板 + 道具集 + 窗景。首发 3 套:「夜间研究所」(暖木书房)、「指挥中心」(深蓝霓虹)、「Meme Lab」(粉紫霓虹)。
6. **每个 agent 有自己的场景**:点击任一 agent → 镜头推进到它的「小房间」(雷达的天文台、实验室的烧杯与回测曲线、风控的瞭望塔与金库门、执行的交易台、市场台的小铺子、复盘的图书馆、组合经理的账本墙、论点台的线索板、总指挥的作战桌),房间里只放它的 3 个关键数 + 一个「打开工作台」按钮,Esc/返回回到全景。

## 2. 两个布局方案(原型都做,Jacky 挑)

**A. 开放办公室(Open Floor)**:一个大房间,9 张工位围着中央会议桌/全息地球;走廊连成网,交接信封沿走廊跑。最像概念图 1/2/3。
**B. 大楼剖面(Tower)**:像《Tiny Tower》/蚂蚁农场的楼宇剖面,每个 agent 一层小房间,从上到下 = 信息流向(雷达在顶楼 → 论点 → 实验室 → 组合 → 风控 → 执行在底楼,市场台在侧楼);交接信封坐电梯上下。每个房间天然就是「单独场景」,点进去放大。游戏感最强、手机竖屏也好放。

两者共用:右栏(3 件事)、顶栏(品牌 + 3 个关键数 + 主题切换 + 声音开关预留)、点 agent 进房间、主题切换。

## 3. 技术

- 纯 Canvas 2D,低分辨率画布(约 480×270 或 320×... 按方案)整数倍放大 + `image-rendering: pixelated`,真像素感;12fps 像素动画 + 60fps 的平滑位移(信封/走路)。
- 美术全程序化:精灵 = 字符串网格 + 调色板(沿用现有 roles.ts 的 SHAPES 与角色色),地砖/墙/窗/道具用小函数画;不引外部图片、无新依赖。
- 引擎与数据解耦:`FloorWorld`(状态:agents、handoffs、theme、time)→ `render(ctx, world, t)`;React 只喂数据(现有 /api/bots、/api/activity、overview、execution 这些 query 不变)。
- 原型先用 mock 数据,页面 `packages/webui/floor-lab/a.html`、`b.html`(vite dev 直接托管:http://127.0.0.1:5191/floor-lab/a.html)。敲定后把选中的引擎搬进 `src/components/floor-v4/`,接真数据替换 #floor。
- 可访问性:`prefers-reduced-motion` 时只保留必要动效;所有画布里的信息在右栏/房间卡片里有文字版。
